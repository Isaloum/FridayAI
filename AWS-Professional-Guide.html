Master these questions to ace your AWS interviews

🎯 What's the difference between S3 and EBS?

Amazon S3 (Simple Storage Service):

  • Object storage accessible via REST API
  • Unlimited storage capacity
  • 99.999999999% (11 9's) durability
  • Best for: Static websites, backups, data archiving

Amazon EBS (Elastic Block Store):

  • Block-level storage that attaches to EC2 instances
  • Limited to single AZ (can be backed up to S3)
  • High IOPS performance for databases
  • Best for: Database storage, file systems, operating systems

💰 How would you optimize AWS costs?

💡 Cost Optimization Strategies

  1. Right-sizing: Use CloudWatch metrics to identify underutilized resources
  2. Reserved Instances: Commit to 1-3 years for up to 75% savings
  3. Spot Instances: Use for fault-tolerant workloads (up to 90% savings)
  4. Auto Scaling: Match capacity to actual demand
  5. S3 Intelligent Tiering: Automatic cost optimization for storage
  6. Schedule Resources: Turn off dev/test environments when not in use
  7. Use Savings Plans: Flexible pricing model for consistent usage

🔒 Explain the AWS Shared Responsibility Model

🔐 Security Responsibilities

AWS Responsibility (Security OF the Cloud):

  • Physical security of data centers
  • Hardware and software infrastructure
  • Network controls and host operating system patching
  • Service configuration and vulnerability patching

Customer Responsibility (Security IN the Cloud):

  • Customer data and encryption
  • Identity and access management (IAM)
  • Operating system updates and security patches
  • Network and firewall configuration
  • Application-level security
