INTERVIEW PREP

❓ Common Interview Questions

• "Design a scalable web application"
→ ELB + EC2 + RDS + Auto Scaling + CloudFront

• "How to reduce costs?"
→ Reserved Instances, Spot Instances, Right-sizing

• "Disaster recovery strategy?"
→ Multi-AZ deployment, Cross-region backups

• "Handle millions of users?"
→ CloudFront + Auto Scaling + Load Balancers

• "Secure an application?"
→ IAM + VPC + WAF + Encryption (KMS)

• "Database choice?"
→ RDS (structured), DynamoDB (fast), Redshift (analytics)
Pro Tip: Always ask about requirements first: budget, performance, compliance, scale
